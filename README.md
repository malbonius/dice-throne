# Dice Throne Playtest 0.29.0

Forgemaster joins **Vanguard** with the Mines, the Forge, all three Ore types, six armour pieces and the optional **Mine Time!** promo.

1. Extract this ZIP over your 0.28.0 build.
2. Upload the changed files to GitHub Pages, keeping the existing `docs` folder.
3. Open the app online until it shows **Playtest 0.29.0** and **Ready for offline play**.
4. Select **Vanguard → Forgemaster** for either seat.
