# Dice Throne Playtest 0.28.0

Duelist joins **Vanguard** with the Footwork Track, Guard Break, Disarm, a 32-card deck and the optional **True Swordsman!** promo.

## Update from 0.27.0

1. Extract this ZIP over your working 0.27.0 repository or assembled release.
2. Upload the changed files to GitHub Pages, keeping the existing `docs` folder.
3. Open the app online until it shows **Playtest 0.28.0** and **Ready for offline play**.
4. Select **Vanguard → Duelist** for either seat.

Reposition requires one or two Steps during upkeep. Moving backward with Reposition grants one Guard Break. Footwork can apply one bonus per turn and resolves before damage. A card drawn from the track can still be played in that damage window.
