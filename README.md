# Dice Throne Playtest 0.26.0

Raveness completes the **Outcasts** roster. The update includes her board, dice, Nevermore, Feather and Hex tokens, 32-card deck and optional **Fiend or Fowl!** promo.

## Update from 0.25.0

1. Extract this ZIP over your working 0.25.0 repository or assembled release.
2. Upload the changed files to GitHub Pages, keeping the existing `docs` folder.
3. Open the app online until it shows **Playtest 0.26.0** and **Ready for offline play**.
4. Select **Outcasts → Raveness** for either seat.

Nevermore starts with Raveness at zero vitality. While on the opponent, he triggers a die roll during their upkeep. Resolve each activation separately. Feathers can alter the Nevermore die or trigger an activation outside that die roll. In a mirror match, Feathers can only modify the roll for their owner's Nevermore. Hex renders sixes blank until the afflicted hero ends their turn.
