# Dice Throne Playtest 0.27.0

Druid joins **Vanguard** with Druid, Bear and Cat forms, both board overlays, Shape Shift, Regenerate, Wound, a 32-card deck and the optional **One with Nature!** promo.

## Update from 0.26.0

1. Extract this ZIP over your working 0.26.0 repository or assembled release.
2. Upload the changed files to GitHub Pages, keeping the existing `docs` folder.
3. Open the app online until it shows **Playtest 0.27.0** and **Ready for offline play**.
4. Select **Vanguard → Druid** for either seat.

Druid can shift into Cat after an offensive ability grants Shape Shift and still get the Cat attack bonus. To roll four defence dice, shift into Bear while the opponent is announcing the attack. Shifting into Bear after rolling keeps the original roll and enables Bear's prevention. When Regenerate is already at its stack limit, the engine automatically flips a 1-point token to its 2-point side if one is available.
