# Dice Throne Playtest 0.30.0

Sun Elf completes **Vanguard** with the Sun Dial, Charged Gem, Sun Marked and the optional **Shine Upon Us!** promo.

1. Extract this ZIP over your 0.29.0 build.
2. Upload the changed files to GitHub Pages, keeping the existing `docs` folder.
3. Open the app online until it shows **Playtest 0.30.0** and **Ready for offline play**.
4. Select **Vanguard → Sun Elf** for either seat.
