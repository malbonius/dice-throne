# Dice Throne Playtest 0.20.0

Tactician joins **Season Two** in both player selectors. The update includes his board, both sides of the leaflet, dice, status tokens and unique card artwork. His deck has 32 standard cards and the optional **Upper Hand!** promo.

## Update from 0.19.0

1. Extract this ZIP over your working 0.19.0 repository or assembled release.
2. Upload the extracted files to the existing GitHub Pages branch. Keep the rest of the repository and the existing `/docs` publish folder.
3. Open the app online and wait for **Playtest 0.20.0** and **Ready for offline play**.
4. Choose **Season Two → Tactician** and start a match.

## Rules covered

- Tactician starts with 2 Tactical Advantage. When a gain would exceed its cap, you can spend existing tokens before collecting the full batch. Higher Ground! increases the cap for the rest of the match.
- Constrict charges 1 CP per additional Roll Attempt. A reroll bought with Tactical Advantage is a single-die effect and does not use an attempt.
- Profiteer checks Blind or Blinding Light before rolling its effect die. A Medal draws a card and starts a new Offensive Roll Phase without triggering Cursed Pirate’s Powder Keg.
- Tactical Advantage can apply Targeted in time to add damage to an ongoing attack. Status transfers are available during your Main Phase.
