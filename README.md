# Dice Throne Playtest 0.24.0

Necromancer joins Headless Horseman under **Outcasts**. This update includes his board, dice, tokens, Undead reference, 33-card deck and optional **Skeletal Structure!** promo.

## Update from 0.23.0

1. Extract this ZIP over your working 0.23.0 repository or assembled release.
2. Upload the changed files to GitHub Pages, keeping the existing `/docs` folder.
3. Open the app online until it shows **Playtest 0.24.0** and **Ready for offline play**.
4. Select **Outcasts → Necromancer** for either seat.

Unearth covers the chosen ability and any alternate ability on its upgrade. Activated Undead roll together at the end of the Roll Phase, unless Deadman’s Party or Necro-Dancer! waives the roll. Resurrect returns the hero to 5 Health and locks CP and cards for the rest of the match. Corpses and Undead remain available.
